# Память народа — выгрузка документов 365 сд

## Что это

Портал Министерства обороны «Память народа», раздел «Документы частей». Выгрузка по фильтру: воинская часть `365сд`, период 01.10.1941–01.05.1942, все типы документов. Найдено 108 карточек, из них 100 со сканами.

В отличие от сайта 365sd.org, здесь лежат **первичные документы ЦАМО**: боевые приказы и донесения самой 365-й дивизии, журналы боевых действий 29-й, 30-й, 39-й армий и Калининского фронта, отчётные карты Западного фронта.

## Как получено

Портал закрыт антибот-защитой: автоматические запросы из командной строки и headless-браузера получают «Проверьте, что вы не человек». Поэтому выгрузка шла из обычного браузера пользователя: страница портала по скрипту собирала карточки выдачи и передавала файлы листов на локальный приёмник (`127.0.0.1`), откуда они раскладывались в Obsidian.

- Каталог выгрузки: `data/cache/pamyat-naroda/catalogue.json` — 108 записей: идентификатор карточки, тип, название, период, дата документа, дело, лист, путь к файлу, размер, sha256, ссылка на портал.
- Список без сканов: `data/cache/pamyat-naroda/catalogue.json` → `archive_order`, разбор — `docs/research/Память народа — документы без сканов (на заказ в ЦАМО).md`.
- Файлы листов: Obsidian `Хобби/365сд/Исходники/ЦАМО — Память народа/<передача>/<фонд-опись-дело>/p<лист>.jpg` (872 МБ).

Права: документы — архивные материалы Минобороны, опубликованные порталом для свободного доступа; копии хранятся локально для исследования, в репозиторий не выкладываются.

## Как читаются реквизиты

Идентификатор дела на портале кодирует шифр: `208-0002511-0275` = ф. 208 (полевое управление Западного фронта), оп. 2511, д. 275. Реквизиты в данных помечены как **выведенные из пути портала**, а не прочитанные с титульного листа — это разные степени достоверности.

## Что это даёт проекту

- Боевые приказы и донесения 365 сд за декабрь 1941 — прямые свидетельства вместо пересказа книги.
- Журналы боевых действий армий и фронта — контекст для событий, где дивизия упоминается.
- Отчётные карты ЗапФ и КалФ — основа для линии фронта, пусть и частично (шесть карт на портале без сканов).

## Ограничения

- Восемь документов (6 отчётных карт, журнал за ноябрь 1941, ЖБД 1-го кавкорпуса) не имеют опубликованных листов: просмотрщик отвечает «нет страниц», любой номер листа даёт 404. В данные не внесены.
- Типы карточек портала грубее номинала проекта: «Рапорты», «Сведения», «Планы операций» сводятся к `other`, «Директивы» и «Приказы» — к `combat-order`. Соответствие задано в `data/registry.json` → `portal_types`.
- Сканы не распознаны: текст документов в данные не извлечён, только регистрация с реквизитами.
