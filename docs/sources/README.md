Разбор и сводка по деду — `docs/research/Бизяев ЕМ — сводка и расхождения.md`.

Сведения о людях с пометкой вида свидетельства (`data/people.json`, поле `claims`) выводятся в `docs/research/Люди — что известно (сгенерировано).md`: по каждой персоне все утверждения с видом свидетельства и источником, отдельно расхождения и люди с единственным сведением.

Документы (`data/documents.json`) и записи именных списков (`data/rosters.json`) ссылаются на носитель — страницу снимка; реквизиты в хронологии печатаются из документа, а не из текста разбора.

Веб-источники адресуются по `url` страницы внутри снимка: без снимка источник не регистрируется, без `url` факт не принимается. Источники, связанные `derived_from`, считаются одной линией передачи.

Машиночитаемый набор фактов боевого пути (`data/`, проверяется `tools/validate.py`) — источник истины для сборки; md в этом каталоге остаются транскрипцией исходников. Сгенерированная хронология — `docs/research/Боевой путь — хронология (сгенерировано).md`.
