# Положения частей: как вносить и чего не делать

Слой `data/positions/<год>.json` хранит **наблюдённые** состояния формирований: кто, где, когда и по какому документу. Это основной слой таймлайна; линия фронта (`front_lines`) остаётся для документов, где фронт нарисован одной линией.

## Запись

```jsonc
{
  "id": "pos-1941-12-15-2200-1215sp-borisovo",
  "unit": "1215sp",
  "as_of": { "date": "1941-12-15", "time": "22:00", "precision": "timestamp" },
  "kind": "cp",
  "place": "pl-borisovo",
  "label": "1/1215 сп — БОРИСОВО, выставив заслон в районе развилки дорог у высоты 114,6",
  "sheet": {
    "source_id": "src-pamyat-naroda",
    "locator": { "page": 1, "quote": "1/1215 сп — БОРИСОВО, выставив заслон…" },
    "colour": null,
    "legend": "оперсводка перечисляет пункты, рубежи не нанесены"
  },
  "basis": "text",
  "accuracy_m": 2000,
  "status": "черновик"
}
```

Обязательно: `id`, `unit`, `as_of`, `kind`, `label`, `sheet`, `basis`, `accuracy_m`, `status`. Место задаётся либо `geometry`, либо `place` — хотя бы одно.

## Правила

1. **Время — как в документе.** «на 9:00 11.12.1941» → `time: "09:00"`, `precision: "timestamp"`. Часовой пояс не приписывается: в документах местное время.
2. **Геометрия соответствует рисунку.** На карте рубеж — `sector` (LineString); только стрелка — `route`; район — `area`; КП — `cp`. Превращать стрелку в полосу обороны нельзя.
3. **Текст — тоже наблюдение.** Пункт из сводки идёт с `basis: "text"`, `kind: "cp"`, `accuracy_m: 2000`. Это не «подсказка для интерполяции», а равноправный факт, просто менее точный.
4. **Несколько положений одной части на одном листе — норма.** Различаются `as_of` и, если нужно, `sheet.colour` / `sheet.legend`.
5. **Расчётных точек здесь нет.** Признак `derived` в исходных данных — ошибка проверки.

## Расчёт для анимации

```bash
python3 tools/trajectories.py            # пересчитать data/dist/trajectories.geojson
python3 tools/trajectories.py --check    # только отчёт и предупреждения
```

Между соседними наблюдениями одного формирования добавляются точки с шагом 6 часов (настраивается `--step-hours`). Каждая расчётная вершина помечена: `derived: true`, `between: ["pos-…", "pos-…"]`, `method: "linear"`, `speed_km_day`, `movement`.

Отказ от расчёта (с предупреждением в отчёте):

- скорость выше верхней границы типа (`movement_rates`: пехота 30, лыжники 40, конница 60, автотранспорт 120, железная дорога 300 км/сутки);
- разрыв больше 10 суток (`--max-gap-days`);
- у одного из положений нет координат.

## Чего не делать

- Не хранить расчётные точки в `data/positions/` — они станут неотличимы от наблюдений.
- Не «сшивать» полосы разных частей в общую линию фронта: это синтез.
- Не подставлять координаты по памяти или «на глаз по подписи»: пока деревня не привязана, положение живёт с `place` без геометрии и в анимацию не попадает — это честный статус, а не недоработка.
