# Spec Delta

## Purpose

Источник может состоять из нескольких файлов: подборка писем, альбом, многотомное дело. Контракт «один файл на источник» заставлял держать остальные части в примечании, то есть вне проверок.

## ADDED Requirements

### Requirement: Источник хранит все свои файлы

Источник SHALL описывать свои файлы массивом `files`, где каждый элемент содержит путь относительно корня хранилища (`path`) и контрольную сумму (`sha256`); массив SHALL содержать минимум один элемент. Поля `vault_path` и `sha256` на уровне источника не используются.

#### Scenario: Подборка из трёх частей
- **WHEN** у источника три файла (расшифровки, оригиналы, фотографии)
- **THEN** все три записаны в `files`, и проверка сверяет существование и sha256 каждого

#### Scenario: Второй файл потерян
- **WHEN** одного из файлов нет в хранилище
- **THEN** проверка называет именно этот путь и сообщает, что источник неполон

#### Scenario: Источник без файлов
- **WHEN** массив `files` пуст или отсутствует у вида, которому файлы нужны
- **THEN** проверка отклоняет источник

### Requirement: Роль файла описывает его содержимое

Элемент `files` SHALL поддерживать поле `role` из перечня `file_roles` реестра (`original`, `scans`, `transcription`, `photos`, `reference`, `appendix`, `other`); указывать роль не обязательно, но если указана — она SHALL быть из перечня.

#### Scenario: Неизвестная роль
- **WHEN** в `role` указано значение вне `file_roles`
- **THEN** проверка сообщает о неизвестной роли и перечисляет допустимые

#### Scenario: Роль не указана
- **WHEN** у файла нет `role`
- **THEN** это не ошибка: файл проверяется по пути и sha256 как обычно

### Requirement: Один и тот же файл не считается двумя частями

Внутри одного источника повтор `path` SHALL быть ошибкой. Совпадение файла между разными источниками SHALL быть предупреждением.

#### Scenario: Дубль внутри источника
- **WHEN** один и тот же путь указан дважды в `files`
- **THEN** проверка отклоняет источник

#### Scenario: Файл в двух подборках
- **WHEN** файл входит и в подборку писем, и в альбом
- **THEN** проверка предупреждает, но не блокирует: фрагмент может принадлежать двум собраниям
