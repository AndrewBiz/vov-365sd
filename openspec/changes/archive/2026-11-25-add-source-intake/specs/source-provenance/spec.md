# Spec Delta

## ADDED Requirements

### Requirement: Веб-источник проходит те же проверки цепочки, что и архивный

Для источника вида `website` проверка SHALL подтверждать существование производной-разбора в `docs/sources/`, существование снимка и разрешимость каждого `url`-локатора фактов, ссылающихся на этот источник.

#### Scenario: Факт ссылается на веб-источник без url
- **WHEN** факт имеет провенанс на веб-источник, но локатор без `url`
- **THEN** проверка отклоняет факт как «неполный провенанс веб-источника»

#### Scenario: Архивный источник не требует url
- **WHEN** факт опирается на архивный документ с локатором `page`
- **THEN** требование об `url` к нему не применяется

### Requirement: Связь производности видна в провенансе

Если факт подтверждается источником и его производной, вердикт проверки SHALL прямо называть оба источника и характер связи, чтобы понижение статуса было объяснимым, а не молчаливым.

#### Scenario: Диагностика понижения
- **WHEN** статус «выверено» понижен из-за связи `derived_from`
- **THEN** сообщение содержит идентификаторы обоих источников и слово «производная»
