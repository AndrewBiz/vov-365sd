# Задачи

## 1. Контракт данных

- [ ] 1.1 `data/schemas/position.schema.json`: часть, `as_of` (дата, время, точность), вид геометрии, `label`, `sheet` (source_id, локатор, цвет, легенда), `basis`, `accuracy_m`, `status`.
- [ ] 1.2 `data/registry.json`: `position_kinds` (`sector`, `line`, `area`, `cp`, `route`), `position_basis` (`map`, `text`, `map+text`), `movement_rates` (пехота 30, лыжники 40, конница 60, автотранспорт 120, железная дорога 300 км/сутки), расширение `date_precision` значением `timestamp`.
- [ ] 1.3 `data/positions/1941.json`, `data/positions/1942.json` — пустые наборы с валидной шапкой.
- [ ] 1.4 Проверки в `tools/validate.py`: известность формирования, формат времени `HH:MM`, геометрия в `front_bbox`, полоса ≥ 2 точек, обязательные `accuracy_m` и `basis`, запрет `derived` в исходных данных.

## 2. Данные первого прохода

- [ ] 2.1 Внести положения 365 сд и её полков по разобранным сводкам (11–31.12.1941): 1211/1213/1215 сп, штаб дивизии — из текстов (`basis: text`, `kind: cp`/`area`, точность 2000 м).
- [ ] 2.2 Внести положения с немецких листов 1:100 000 (Ржев IX.1942, Клин VI.1942) после привязки — `basis: map`, `kind: sector`, точность 250 м.

## 3. Оцифровка полос

- [ ] 3.1 Расширить `tools/trace_front_line.html`: несколько полос, выбор формирования, выбор времени (`date` + `time`), цвет, легенда, экспорт в формат положений.
- [ ] 3.2 Проверка: выгруженный файл проходит схему и попадает в `data/positions/` без ручной правки.

## 4. Производные траектории

- [ ] 4.1 `tools/trajectories.py`: упорядочивание наблюдений по формированию, расчёт промежуточных точек с шагом 6 часов, отказ при неправдоподобной скорости и при разрыве > 10 суток.
- [ ] 4.2 Выход: `data/dist/trajectories.geojson` с пометками `derived`, `between`, `method`, `speed_km_day`; предупреждения — в консоль и в отчёт сборки.
- [ ] 4.3 Тесты: правдоподобный переход считается; быстрый — отклоняется с предупреждением; длинный разрыв — не заполняется; центроид полосы используется как точка отсчёта.

## 5. Анимация и отчёты

- [ ] 5.1 `frames.json`: слой положений с кадром 6 часов, отдельно наблюдённые и расчётные.
- [ ] 5.2 HTML-просмотрщик: пунктир для расчётных участков, переключатель «показывать расчёт», подпись с временем из документа.
- [ ] 5.3 Отчёт «Боевой путь»: колонки времени, формирования, вида геометрии, базиса, точности и пометки «расчёт» для производных.
