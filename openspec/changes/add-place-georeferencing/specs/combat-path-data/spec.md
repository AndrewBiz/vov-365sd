# Spec Delta

## ADDED Requirements

### Requirement: Событие может задавать место ссылкой

Событие SHALL иметь возможность вместо собственной геометрии ссылаться на место из реестра мест; ссылка обязана указывать на существующее место.

#### Scenario: Ссылка на несуществующее место
- **WHEN** событие ссылается на идентификатор, отсутствующий в реестре мест
- **THEN** проверка отклоняет событие и называет отсутствующий идентификатор

#### Scenario: Событие без места и без геометрии
- **WHEN** у события нет ни геометрии, ни ссылки на место
- **THEN** событие принимается с уровнем локализации «приблизительно»

### Requirement: Геометрия события выводится из места при сборке

При сборке событие со ссылкой на место SHALL получать геометрию из координат этого места, а уровень локализации — из уровня точности места. Собственная геометрия события имеет приоритет над местом.

#### Scenario: Событие локализуется через место
- **WHEN** у события есть ссылка на место с координатами
- **THEN** в FeatureCollection событие попадает точкой этого места с уровнем локализации места

#### Scenario: Собственная геометрия важнее места
- **WHEN** у события заданы и собственная геометрия, и ссылка на место
- **THEN** в FeatureCollection используется собственная геометрия события

#### Scenario: Место без координат
- **WHEN** место, на которое ссылается событие, координат не имеет
- **THEN** событие не попадает в FeatureCollection, остаётся в хронологии с пометкой о нелокализованном месте
