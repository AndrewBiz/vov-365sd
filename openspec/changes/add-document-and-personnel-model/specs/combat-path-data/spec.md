# Spec Delta

## ADDED Requirements

### Requirement: Событие может ссылаться на документы

Событие SHALL иметь возможность перечислять документы, которыми оно подтверждено; каждая ссылка обязана указывать на существующий документ реестра.

#### Scenario: Ссылка на несуществующий документ
- **WHEN** событие ссылается на идентификатор документа, отсутствующий в реестре
- **THEN** проверка отклоняет событие и называет отсутствующий идентификатор

#### Scenario: Событие без документов
- **WHEN** у события нет ссылок на документы
- **THEN** событие принимается: документальное подтверждение необязательно

### Requirement: Документальное подтверждение выводится в хронологии

При сборке рядом с событием SHALL выводиться список подтверждающих документов с типом, датой и архивными реквизитами в читаемом виде.

#### Scenario: Событие с приказом
- **WHEN** событие подтверждено боевым приказом с реквизитами
- **THEN** в сгенерированной хронологии под событием видно тип документа, его дату и «ф. … оп. … д. … л. …»

#### Scenario: Документ без реквизитов
- **WHEN** у документа реквизиты не установлены
- **THEN** в хронологии вместо реквизитов явно печатается «реквизиты не установлены»
