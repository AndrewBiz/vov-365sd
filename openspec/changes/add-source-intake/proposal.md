# Proposal

## Why

Проект пополняется веб-источниками (форум «Забытый полк», сайт 365sd.org на 142 страницы), но контракт данных этого не предусматривает: вида источника «сайт» нет, локатор не умеет URL, а производность источников не выражается. Из-за этого цитату с сайта невозможно воспроизвести по локатору, снимок и версия источника не фиксируются, а сайт и скопировавшая его презентация рискуют попасть в данные как два независимых подтверждения — и поднять статус факта до «выверено» на одном свидетельстве.

## What Changes

- Вводится вид источника `website` с обязательными полями снимка: дата снимка, каталог выгрузки, карта `URL → файл`. Источник без снимка не регистрируется.
- В локатор факта добавляется поле `url`; цитата с веб-источника обязана указывать конкретную страницу снимка.
- В реестр источников добавляется `derived_from`: явная связь «этот источник является производной от такого-то».
- Правило независимости: источники, связанные цепью `derived_from` (в любую сторону, транзитивно), не считаются независимыми подтверждениями для статуса «выверено».
- Вводится инструмент снимка сайта: обход с ограничением частоты, сохранение текста каждой страницы, карта URL, детерминированный результат; повторный снимок даёт список изменений относительно предыдущего.
- Валидатор проверяет: снимок существует, каждая `url`-цитата разрешается в файл снимка, `derived_from` ссылается на существующие источники, «выверено» не опирается на связанные источники.

## Capabilities

### New Capabilities

- `source-intake`: приём веб-источников — снимок с версией, карта страниц, URL-локаторы, фиксация производности и правило независимости источников при подтверждении фактов.

### Modified Capabilities

- `source-provenance`: расширяется понятие источника — добавляются веб-источники со снимком и связь `derived_from`. Существующие требования к архивным документам не меняются.

## Impact

- `data/schemas/source.schema.json` — вид `website`, поля `snapshot_at`, `cache_path` (обязателен для сайта), `derived_from`.
- `data/schemas/fact.schema.json` — поле `url` в локаторе.
- `data/sources.json` — миграция двух существующих веб-источников (`src-365sd-org`, `src-polk-forum-2617`) на новый вид и url-локаторы; `src-pptx-365.derived_from = [src-365sd-org]`.
- `tools/validate.py` — новые проверки; `tools/snapshot_site.py` — новый инструмент (единственное место, кроме геокодирования, где есть сеть).
- `data/cache/site-365sd/`, `data/cache/polk-2617/` — карта URL и выгрузки в репозитории.
- `README.md` — порядок добавления веб-источника.
- Сети требует только снимок; проверки и сборка остаются офлайновыми.
